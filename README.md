# Algoritmos de Busca em Largura (BFS) - Atividade

Repositório contendo as implementações referentes à atividade da disciplina de **Estrutura de Dados II**. O objetivo deste projeto é aplicar os conceitos de Busca em Largura (Breadth-First Search) para a resolução de diferentes problemas computacionais.

## 📁 Estrutura do Projeto

O código-fonte está organizado nos seguintes pacotes:

* **`aplicativo1` (Quebra-Cabeça Deslizante):** 
  * Implementação de um solucionador para o jogo de quebra-cabeça deslizante.
  * **Classes principais:** `GerenciadorTabuleiro`, `Quebra_cabeca_Deslizante` e `Main`.
* **`aplicativo2` (Rotas de Viagem):**
  * Aplicação do algoritmo BFS para encontrar a melhor rota entre diferentes pontos de viagem.
  * **Classe principal:** `RotaViagem`.
* **`principal`:**
  * Contém a classe `Principal`, que serve como ponto de entrada geral para gerenciar e executar as diferentes aplicações do projeto.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java 17
* **Paradigma:** Orientação a Objetos e Estruturas de Dados

## 🚀 Como Executar

1. Certifique-se de ter o JDK 17 ou superior instalado na sua máquina.
2. Clone este repositório.
3. Abra a pasta do projeto na sua IDE (IntelliJ, Eclipse, etc.).
4. Execute a classe `Principal` no pacote `principal` para navegar pelas opções, ou rode as classes `Main` de cada pacote individualmente para testar soluções específicas.
